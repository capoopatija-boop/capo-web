# CAPO autopraonica

Statička početna stranica i 7 kratkih početnih stranica usluga.

## Objavljivanje
1. U GitHubu napraviti novi repozitorij `capo-web`.
2. Prenijeti sadržaj ove mape (index.html mora biti u korijenu).
3. Cloudflare Pages → Create project → Connect to Git → odabrati repozitorij.
4. Framework preset: None; build command: prazno; output directory: `/` (root).
5. Dodati domenu capo.com.hr nakon povezivanja.

## Važno
- Stranice usluga zasad su kratki nacrti, ne puni SEO tekstovi od 1000–1200 riječi.
- Sučelje ima HR/EN/DE/IT prijevode u app.js; SEO prijevode/odvojene jezične URL-ove dodati kasnije.
- Provjeriti točnost Maps lokacije prije objave.
- Početne fotografije ustupljene su u razgovoru.
